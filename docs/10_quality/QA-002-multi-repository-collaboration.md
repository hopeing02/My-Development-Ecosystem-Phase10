# QA-002 다중 저장소 협업 품질 기준

## 필수 검증

- 정상 및 비정상 `.mde/project.yaml` 로딩 테스트
- 필수 필드, 명령 목록, 브랜치 패턴 검증 테스트
- 작업 `assignee` 검증 테스트
- 담당자 기반 브랜치 생성 및 불일치 테스트
- 보호 브랜치에서 commit/push 차단 테스트
- 테스트·빌드 명령 성공, 실패, 실행 순서 테스트
- 기존 설정이 없는 실행 경로의 회귀 테스트

## Pull Request 기준

- `main` 대상 Pull Request만 병합 경로로 사용한다.
- 최소 1명의 승인을 요구한다.
- MDE Core 단위·통합 테스트를 필수 검사로 지정한다.
- 프로젝트 저장소는 `.mde/project.yaml`의 테스트·빌드 명령을 필수 검사로 실행한다.

## 완료 판정

문서, 소스, 테스트가 일치하고 전체 테스트가 통과하며 실제 비밀정보가 포함되지 않았을 때 구현 단위를 완료한다.
