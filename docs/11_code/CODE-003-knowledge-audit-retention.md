# CODE-003 Knowledge 감사 로그 30일 보존 구현

- 버전: 1.2.0
- 상태: Implemented
- 작성일: 2026-07-22

## 구현

`KnowledgeAuditLogger.prune()`이 감사 이벤트를 기록하기 전에 만료 로그를 검사한다. 기준일에서 30일을 뺀 날짜 이하의 정확한 일별 감사 로그만 제거한다.

## 보호 장치

- `knowledge-YYYY-MM-DD.log` 정규식 완전 일치
- 로그 디렉터리 직접 자식만 검사
- 정규 파일만 허용
- 심볼릭 링크 제외
- 확인된 로그 디렉터리 밖 경로 제외
- 최소 보존 기간 1일 검증
- Source 경로와 무관한 독립 처리
