## 1. 입력 및 실행 방식

사용자가 이전에 승인한 Downloads 폴더와 하위 폴더에서 실제 HWPX 1건을 확인했다.
그중 이전 OT1-001의 SHA-256과 일치하는 원본이 정확히 1건이었다.
OT1-002/OT1-003에 사용할 추가 실제 문서는 지정되지 않아 실행하지 않았다.
합성 sentinel을 실제 문서 3종 중 하나로 계산하지 않았다.

첨부 DOC-PARSER-OT1-R2_로컬검증.py를 수정 없이 Git 제외 .mde/document-parser-ot1-r2에 복사해 실행했다.
검사 도구의 import 경로 검사와 FIX1 합성 중첩 sentinel이 실제 문서 읽기 전에 통과했다.
Python 3.12 기존 검증 환경을 재사용했고 PYTHONPATH는 FIX1 worktree의 소스를 우선했다.
DOC_PARSER_CASE=OT1-001, DOC_PARSER_SAVE_LOCAL=1로 실행했으며 검사 스크립트 종료 코드는 0이었다.
