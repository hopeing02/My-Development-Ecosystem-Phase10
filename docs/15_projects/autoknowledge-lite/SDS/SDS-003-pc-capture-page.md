# SDS-003 PC 저장 화면

- 버전: 0.2.1
- 상태: Approved

## 요구사항

PC 사용자가 개발자용 API 문서를 조작하지 않고 브라우저에서 내용을 개인 Vault에 저장할 수 있어야 한다.

## 기능

1. 선택 제목 입력
2. 6개 고정 Vault 폴더 선택
3. 내용 직접 입력
4. 사용자 동작에 의한 클립보드 읽기
5. `/v1/share` 저장 요청
6. 성공·실패 상태 표시

## 제외 범위

- Vault 문서 목록과 검색
- Markdown 편집
- 임의 저장 경로 입력
- 백그라운드 클립보드 감시
- 별도 로그인·서버·데스크톱 설치 프로그램
