# GUIDE-004 PC 저장 화면

- 버전: 0.2.1
- 상태: Active

## 열기

노트북에서 다음 주소를 연다.

```text
http://127.0.0.1:8000/pc
```

## 저장

1. 제목을 필요할 때만 입력한다.
2. `00_Inbox`, `10_Life`, `20_Learning`, `30_Interests`, `40_Reference`, `90_Archive` 중 하나를 선택한다.
3. 내용을 직접 입력하거나 `클립보드 붙여넣기`를 누른다.
4. `Vault에 저장`을 누른다.
5. 완료 메시지를 확인한다.

클립보드 권한이 거부되면 내용 입력 영역을 선택하고 `Ctrl+V`로 붙여넣는다.

## 주의

- AutoKnowledge 서버가 실행 중이어야 한다.
- PC 화면은 Vault 파일을 수정하거나 삭제하는 기능을 제공하지 않는다.
- 저장한 내용은 선택한 폴더에 새 Markdown으로 생성된다.
