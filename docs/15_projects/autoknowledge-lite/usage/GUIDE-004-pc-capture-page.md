# GUIDE-004 PC 저장 화면

- 버전: 0.2.2
- 상태: Active

## 열기

노트북에서 다음 주소를 연다.

```text
http://127.0.0.1:8000/pc
```

## 저장

1. 제목을 필요할 때만 입력한다.
2. `00_Inbox`, `10_Life`, `20_Learning`, `30_Interests`, `40_Reference`, `90_Archive` 중 하나를 선택한다.
3. `이 문서를 참조할 상위 주제 문서`에서 기존 문서를 검색해 필요하면 선택한다.
4. 내용을 직접 입력하거나 `클립보드 붙여넣기`를 누른다.
5. `Vault에 저장`을 누른다.
6. 완료 메시지를 확인한다.

상위 주제 문서를 선택하면 해당 기존 Markdown의 `AutoKnowledge 하위 문서`
섹션에 새 문서 링크가 추가된다. 선택하지 않으면 직전에 PC 웹 화면에서 저장하고
색인까지 완료된 문서를 상위 주제로 사용한다. 이전 웹 저장 문서가 없으면 첫 문서는
상위 주제 없이 저장된다.

클립보드 권한이 거부되면 내용 입력 영역을 선택하고 `Ctrl+V`로 붙여넣는다.

## 주의

- AutoKnowledge 서버가 실행 중이어야 한다.
- 상위 주제 연결을 선택한 경우에만 해당 기존 문서에 새 문서 링크를 추가한다.
- 문서 삭제와 이동은 제공하지 않는다.
- 저장한 내용은 선택한 폴더에 새 Markdown으로 생성된다.
