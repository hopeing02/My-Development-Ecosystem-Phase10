# 2026-07-30 Knowledge Viewer 편집·링크 연결

## 구현

- frontmatter와 fenced/inline code의 링크 오탐 차단
- link occurrence ID·offset·line·column·문맥 저장과 DB migration
- Source별 `read_only`, `editable_in_viewer`, `allow_link_rewrite` 정책
- 문서 변경 미리보기, contentHash 충돌 검사, 2MB 제한
- unknown frontmatter 보존, UTF-8 BOM 유지, 임시 파일 검증과 원자 replace
- `.mde-backups/YYYY-MM-DD` 문서당 최근 10개 백업과 Scanner 제외
- Markdown 저장 후 단일 파일 재색인, 실패 시 파일 유지와 재시도 API
- 같은 Source 대상 검색과 선택 occurrence 링크 재작성
- Viewer 편집·미리보기·미저장 보호·링크 연결·그래프 재조회 UI
- Android private/Tailscale 동일 Origin Command 허용과 공용 Host 차단
- 편집 UI의 본문 링크 occurrence 삭제 및 같은 Source 문서 검색·추가
- 저장·미리보기 실패의 편집기 인라인 오류 표시

## 제한

- 복원 UI와 문서 생성·삭제·이동·파일명 변경은 범위에서 제외했다.
- YAML 데이터 필드는 보존하지만 주석과 원래 YAML 서식은 재출력 시 달라질 수 있다.
- 현재 실행 환경에 연결 가능한 Browser 인스턴스가 없어 실제 브라우저 클릭 E2E는
  수행하지 못했고, Viewer 컴포넌트 테스트와 실제 로컬 HTTP E2E로 분리 검증했다.
- Vite build는 Cytoscape 포함 단일 JS chunk가 500kB를 넘는 경고를 출력한다.
