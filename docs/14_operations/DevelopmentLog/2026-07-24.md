# 오늘 작업

AutoKnowledge Lite v0.2.1 PC 저장 화면을 구현하고 고정 폴더 선택, 클립보드 붙여넣기, 직접 입력과 기존 저장 API 연결을 검증했다.

개인 Git Vault의 활성 경로를 MDE 외부 사용자 전용 경로로 복구하고 기존 노트 21개에 Obsidian 별칭, 정규화 태그, MOC 링크와 검토 속성을 추가했다. 새 노트 자동 연결, 그래프 설정, Templates, Bases와 Dashboard 생성 기능을 구현했다.

# 문제점

개발자용 API 화면은 일반 PC 사용자가 매번 JSON을 직접 작성해야 하고 코드 수정 도구는 Windows ACL 문제로 기존 파일을 읽지 못했다.

환경변수가 MDE 내부 보존 Vault로 되돌아가 정책 문서와 실제 실행 경로가 달랐고, Windows PowerShell 파이프가 패치의 한글 문자열을 손상시켰다. 예약 작업 서버 재시작도 수분 지연됐다.

# 해결

기존 로컬 서버에 의존성 없는 `/pc` 화면을 추가했다. 코드 수정은 모든 원문 기준점이 정확히 한 번 존재하는지 사전검사한 뒤 파일당 한 번만 저장했으며 전체 앱 테스트 55개, MDE 회귀 테스트 146개, Ruff와 앱 formatter 검사를 통과했다.

외부 Vault를 원격 최신 커밋으로 fast-forward하고 내부 보존본과 Git HEAD·tree·파일 수를 검증한 뒤 사용자 환경변수와 자동시작 서버를 전환했다. 기존 노트 원문 불일치 0건, 공백 태그 0건, 위키링크 108개와 반복 실행 변경 0건을 확인했다. 한글 소스는 유니코드 이스케이프로 보호하고 AutoKnowledge 전체 테스트 62개와 Ruff 검사를 통과했다.

# 내일 작업

PC 화면의 실제 브라우저 저장 흐름을 확인하고 필요하면 바로가기 생성 방식을 검토한다.

Obsidian에서 외부 Vault를 처음 열어 Bases 렌더링과 Local Graph 배치를 확인한다.
