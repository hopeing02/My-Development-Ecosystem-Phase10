# 2026-07-29 Development Log

## 오늘 작업

첨부된 Knowledge Graph API 및 Web Viewer v1 지침을 기존 구현과 대조하고,
SQLite 링크 계약, Graph 잘림 메타데이터, API 응답, 로컬 serve 보안, Viewer 검색과
상호작용을 보강했다. production Viewer를 `mde-core` 정적 자산으로 포함했다.

## 문제점

기존 구현은 태그 개수와 그래프 전체·반환 문서 수가 없었고, 검색 UI가 별도 검색
API 대신 그래프 요청에 연결되어 있었다. serve 명령은 외부 host 옵션을 허용했고
production 빌드가 Python 패키지에 포함되지 않았다.

## 해결

서버를 `127.0.0.1`로 고정하고 `--no-open`을 추가했다. 링크 원문·정규화 대상·
heading·표시명을 보존하며 기존 SQLite를 자동 마이그레이션한다. Viewer에는
400ms 검색 디바운스, 검색 결과 중심 이동, 관계 목록, 끊어진 링크 가상 노드,
민감 Source 대화상자와 모바일 레이아웃을 추가했다.

## 내일 작업

기능 범위는 완료됐다. 사용자 승인 후 작은 의미 단위로 커밋하고, 다음 AI 분석
단계는 별도 개발지침과 ADR 검토 후 시작한다.

## 소요시간

구현, 자동 회귀, production build와 실제 로컬 브라우저 E2E까지 한 작업 세션에서
완료했다.
문서 1,000개·Edge 5,000개 성능 기준에서 전체 그래프, depth 2, 검색과 상세
조회가 모두 0.5초 안에 완료됐다.
