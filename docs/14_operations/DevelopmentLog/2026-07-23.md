# 오늘 작업

프로젝트별 사용법 문서를 `docs/15_projects/<project>/usage/`에서 관리하도록 표준과 새 프로젝트 생성 템플릿을 확장했다. AutoKnowledge Lite에 사용법 진입 문서를 추가하고 개인 Vault에 6개 카테고리 안내 폴더를 생성했다. 프로젝트 생성 집중 테스트 19개와 전체 회귀 테스트 144개를 통과했고, 개인 Source 증분 스캔과 기본 검색 제외를 확인했다.

# 문제점

프로젝트 공식 설계·구현·테스트·사용법과 개인 학습·생활 자료의 저장 경계가 명확하지 않았고, 기존 개인 노트를 일괄 이동하면 링크와 Git 이력이 깨질 위험이 있었다. 표준 Ruff 명령이 로컬 의존성 폴더 `.test-deps`까지 검사해 외부 패키지 오류 442건을 보고했다.

# 해결

프로젝트 공식 기록은 프로젝트 문서 트리에 유지하고 개인 Vault는 같은 개인 보안 경계 안에서 폴더로만 분류하도록 결정했다. 기존 `AutoKnowledge/` 노트 17개는 이동하거나 수정하지 않고 SHA-256 일치로 보존을 확인했다. Ruff는 `.test-deps` 제외 검사와 변경 파일 포맷 검사로 이번 변경이 통과함을 분리 검증했다.

# 내일 작업

프로젝트 사용법 템플릿의 실제 생성 결과와 개인 Vault 증분 색인 결과를 확인하고 필요하면 첫 기능별 사용 가이드를 확장한다.
