# DEV-002 다중 저장소 협업 구현 지침

## 1. 적용 관계

이 문서는 STD-002를 구현하기 위한 지침이다. DEV-001의 코드 품질, 작은 단위 개발, 테스트, 문서 동기화 규칙은 유지한다. 저장소 배치에 한해 STD-002와 이 문서가 외부 프로젝트 연동의 기준이 된다.

## 2. 구현 순서

1. `.mde/project.yaml` 모델과 로더를 구현한다.
2. 작업 모델에 `assignee`를 추가하고 브랜치 규칙을 검증한다.
3. `main` 직접 commit 및 push를 MDE 명령에서 차단한다.
4. 프로젝트가 선언한 테스트와 빌드 명령을 실행한다.
5. 프로젝트 템플릿과 GitHub Actions 예제를 제공한다.

각 단계는 소스와 테스트를 함께 제공하고 독립적으로 커밋할 수 있어야 한다.

## 3. 호환성

- 기존 `.mde-project.json`은 자동 변환하지 않는다.
- 신규 협업 기능은 `.mde/project.yaml`이 존재할 때 활성화한다.
- 설정이 없는 기존 MDE 실행 흐름은 현재 동작을 유지한다.
- 저장소 물리 분리는 별도 마이그레이션 작업으로 수행한다.

## 4. 안전 규칙

- 설정 파일에서 임의의 Python 코드를 실행하지 않는다.
- 프로젝트 명령은 인자 목록으로 파싱하여 `shell=False`로 실행한다.
- `main` 보호는 MDE CLI와 GitHub Ruleset 양쪽에 적용한다.
- 실제 토큰, 사용자 이메일, API 키를 템플릿에 포함하지 않는다.
