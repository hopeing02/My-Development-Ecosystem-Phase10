# ADR-005 Knowledge 감사 로그 30일 보존

- 버전: 1.0.0
- 상태: Accepted
- 작성일: 2026-07-22

## 결정

Knowledge 감사 로그는 오늘을 포함한 최근 30일을 보존하고, 30일 보존 경계에 도달한 일별 로그를 다음 감사 이벤트 기록 시 자동 삭제한다.

## 안전 범위

삭제 대상은 사용자 전역 Knowledge 로그 디렉터리 바로 아래의 정확한 `knowledge-YYYY-MM-DD.log` 정규 파일로 제한한다. 다른 이름, 하위 디렉터리, 심볼릭 링크, Source 원본, SQLite와 Source Registry는 삭제하지 않는다.

## 이유

감사 가능성을 유지하면서 사용자 로컬에 운영 로그가 무기한 쌓이는 것을 방지하기 위해서다. 30일은 사용자가 명시적으로 선택한 보존 기간이다.

## 대안

- 90일 보존: 현재 필요보다 길어 선택하지 않음
- 수동 삭제: 누적 관리가 누락될 수 있어 선택하지 않음
- 실행 즉시 삭제: 감사 목적을 훼손하여 거절

## 영향

삭제된 감사 로그는 자동 복구되지 않는다. 별도 장기 보관이 필요하면 보존 경계 전에 사용자가 안전한 백업 위치로 복사해야 한다.
