# ADR-015 Obsidian 지식 그래프 자동화

- 작성일: 2026-07-24
- 상태: Accepted

## 배경

AutoKnowledge Lite가 생성한 개인 Vault 노트에는 제목, 수신 시각과 태그가 있지만
Obsidian 내부 링크가 없어 백링크와 그래프가 실질적인 관계를 표시하지 못한다.
자동 생성 파일명도 길어서 직접 링크를 만들기 어렵고, 공백이 포함된 태그는
Obsidian 태그 규칙과 맞지 않는다.

## 결정

- 새 노트와 기존 노트에 동일한 결정적 메타데이터 규칙을 적용한다.
- 태그는 유니코드 문자, 숫자, 밑줄, 하이픈과 슬래시만 사용하도록 정규화한다.
- 긴 파일명을 직접 사용하지 않아도 되도록 짧은 `aliases` 목록을 생성한다.
- `type`, `status`, `reviewed`, `topics` 속성을 추가한다.
- 각 노트는 하나 이상의 MOC 노트와 `[[내부 링크]]`로 연결한다.
- 기존 노트 정리는 기본 미리보기와 명시적 `--apply` 실행을 분리한다.
- 기존 본문과 원문 구역은 수정하지 않고 관리 대상 속성과 마지막 `## 연결`
  구역만 추가하거나 갱신한다.
- 중복은 자동 삭제하거나 병합하지 않는다. 동일 제목 후보를 표시하고 대표
  노트 링크만 기록한다.
- 개인 Vault Git 저장소의 원격과 이력은 유지하며 MDE 저장소 밖의 사용자
  전용 경로를 활성 원본으로 사용한다.

## 결과

Obsidian Backlinks, Outgoing links, Local Graph와 Bases가 별도 데이터베이스 없이
Markdown 파일의 속성과 내부 링크를 직접 사용할 수 있다. 자동 처리는 반복
실행해도 같은 결과를 내며, 사용자는 `status: to-review` 노트만 검토하면 된다.

## 제외 범위

- 기존 노트 자동 삭제·이동·병합
- AI 판단만으로 대표 노트 확정
- 커뮤니티 플러그인 필수 의존성
- 개인 Vault를 MDE 상위 Git 저장소에 포함
