# ADR-002 MDE Core와 프로젝트 저장소 분리

- 상태: 승인
- 결정일: 2026-07-19

## 배경

MDE를 2~3명의 사용자가 여러 실제 프로젝트에 적용하려면 공통 자동화 코드와 프로젝트 제품 코드의 릴리스 주기, 권한, 이력을 분리할 필요가 있다. 기존 DEV-001은 초기 구현을 위한 단일 모노레포를 전제로 한다.

## 결정

MDE CLI, Agent, Workflow, Template은 하나의 `mde-core` 저장소에서 관리한다. 실제 프로젝트는 각각 독립 저장소로 관리하고 `.mde/project.yaml`을 통해 MDE Core와 연결한다.

모든 작업은 담당자가 기록된 작업 브랜치에서 수행하고 Pull Request로만 `main`에 병합한다. MDE CLI의 로컬 보호와 GitHub Ruleset의 원격 보호를 함께 사용한다.

## 결과

- MDE Core를 여러 프로젝트에서 같은 방식으로 재사용할 수 있다.
- 프로젝트별 권한, 이슈, 릴리스 이력이 분리된다.
- Core 버전과 프로젝트 설정 간 호환성 관리가 필요하다.
- 기존 모노레포 제품의 물리 분리는 별도 마이그레이션과 검증이 필요하다.

## 제외 범위

이번 결정은 현재 저장소의 `apps/` 디렉터리를 즉시 이동하거나 Git 이력을 재작성하지 않는다.
