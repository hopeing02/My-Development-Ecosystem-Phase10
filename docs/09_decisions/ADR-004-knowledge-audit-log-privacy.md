# ADR-004 Knowledge 감사 로그 개인정보 보호

- 버전: 1.0.0
- 상태: Accepted
- 작성일: 2026-07-22

## 결정

Knowledge 운영 감사 로그를 사용자 전역 `~/.mde/knowledge/logs/`에 일별 JSON Lines로 기록한다. Source 생명주기와 스캔 이벤트만 기록하고 검색어·검색 결과·문서 본문·Source 절대경로는 기록하지 않는다.

## 이유

운영 문제와 스캔 결과는 추적해야 하지만 개인·업무 자료의 내용과 위치가 로그를 통해 추가 노출되어서는 안 된다. 구조화된 최소 이벤트는 감사 가능성과 개인정보 최소 수집을 동시에 만족한다.

## 대안

- 모든 CLI 인자와 출력을 기록: 검색어와 민감정보 노출 위험으로 거절
- 로그를 프로젝트 `logs/`에 기록: Git 포함 위험으로 거절
- 감사 로그 없음: Source 변경과 스캔 장애 추적이 어려워 거절

## 영향

로그에는 Source 이름이 포함될 수 있으므로 Source 이름 자체에 민감정보를 사용하지 않는 것이 좋다. 로그 보존 기간과 자동 정리는 v1.1 범위 밖이다.
