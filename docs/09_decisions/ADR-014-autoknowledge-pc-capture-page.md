# ADR-014 AutoKnowledge PC 저장 화면

- 작성일: 2026-07-24
- 상태: Accepted

## 결정

PC 입력 기능은 별도 데스크톱 프로그램이나 독립 웹 서버가 아니라 기존 AutoKnowledge 로컬 서버의 정적 `/pc` 화면으로 제공한다.

## 이유

- 기존 `/v1/share` 검증과 저장 흐름을 그대로 재사용할 수 있다.
- 추가 프로세스, 포트와 사용자 설정이 필요하지 않다.
- 브라우저에서 클립보드 붙여넣기와 직접 입력을 모두 지원할 수 있다.

## 보안 경계

- 저장 폴더는 기존 6개 고정 목록만 표시한다.
- 임의 경로 입력과 파일 탐색 기능을 제공하지 않는다.
- 서버는 기존 `ShareRequest` allowlist로 폴더를 다시 검증한다.
- 클립보드는 사용자가 버튼을 누를 때만 읽는다.
- 페이지에 Vault 문서, 작업 기록과 비밀정보를 표시하지 않는다.
