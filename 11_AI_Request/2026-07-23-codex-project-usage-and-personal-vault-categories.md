## 요청 내용

프로젝트별 설계·기능 추가·정정 기록·사용법 저장 위치를 공식화하고, 새 프로젝트 생성 시 사용법 문서를 자동 생성한다. 개인 Vault는 카테고리별 폴더로 나누되 기존 개인 파일은 이동하거나 수정하지 않는다.

## 제약 조건

- 프로젝트 공식 문서와 개인 자료를 섞지 않는다.
- 개인 Vault 원본 파일을 자동 이동·삭제·수정하지 않는다.
- 개인 Source의 민감 보안 기본값을 유지한다.
- 모든 중요한 설계 변경, 테스트, 개발일지를 기록한다.

## 기대 결과

- 프로젝트별 `usage/` 규칙과 템플릿
- 개인 Vault 폴더 분류 안내
- 기존 개인 노트 보존 검증
- 테스트와 기록 문서
