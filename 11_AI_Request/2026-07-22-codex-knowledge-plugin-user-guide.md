## 목적

MDE Knowledge Plugin v1.2의 실제 사용 절차를 공식 문서로 보존한다.

## 요청 내용

사용자가 제공한 Source 확인, 검색, 태그, 증분 스캔, Source 등록, Category 보안값, 민감 Source 검색, Obsidian 링크, 백링크, Agent 접근, Source 제거, 사용자 데이터 위치, 감사 로그, 제외 폴더 및 일상 사용 흐름을 저장한다.

## 제약 조건

- 원본 자료를 수정하거나 이동하지 않는다.
- 개인 및 업무 Source의 기본 보호 정책을 정확히 설명한다.
- 현재 구현된 CLI 명령만 문서화한다.
- DevelopmentLog에는 정해진 다섯 항목만 사용한다.

## 기대 결과

`docs/05_commands/`에서 확인할 수 있는 실행 가능한 Knowledge Plugin 상세 사용자 가이드와 관련 문서 인덱스 및 개발 기록이 생성된다.
